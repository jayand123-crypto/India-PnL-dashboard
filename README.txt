# India Bunker P&L — iPhone PWA

This package contains your existing HTML dashboard converted into an installable Progressive Web App (PWA).

Files:
- index.html — your dashboard
- manifest.json — app metadata/icon configuration
- sw.js — offline caching
- icon-192.png / icon-512.png — app icons

Important:
A PWA must be opened from an HTTPS website to show Safari's “Add to Home Screen” app behavior reliably. The next step is to host this folder on an HTTPS site. Once hosted, open it in Safari and use Share → Add to Home Screen.
